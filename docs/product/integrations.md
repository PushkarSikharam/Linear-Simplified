# Integrations

Integrations connect Pixel with tools used by engineering teams.

GitHub can sync pull requests, commits, and issue references. Slack can turn messages into issues and send workflow updates. Jira import can bring existing project and issue data into the demo workspace. Integrations are useful when a visitor asks how work connects across tools or how migration from Jira might work.

Use Integrations when a visitor asks about GitHub, Slack, Jira import, connected tools, migration, or workflow automation.
