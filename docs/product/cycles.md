# Cycles

Cycles organize work into time-boxed planning periods so engineering teams can decide what to focus on, track progress, and review what shipped.

Teams use cycles for sprint planning, active cycle health, remaining work, completed issues, and planning follow-up. A cycle view should make it easy for an engineering manager to see what is done, what is in progress, what remains, and whether the team is on track before the cycle ends.

Use Cycles when a visitor asks about sprint planning, two-week planning, burndown, cycle progress, or replacing Jira sprint workflows.
