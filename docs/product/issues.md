# Issues

Issues are the core work items used to track bugs, tasks, improvements, and customer-impacting work.

Each issue can have an owner, priority, status, project, and description. Assignment is handled from the issue detail panel, where a team member can be selected as the assignee. Issue tracking is useful when a visitor asks about bug triage, ticket ownership, priorities, or how work moves from todo to in progress to review.

Use Issues when a visitor asks about bugs, tickets, triage, issue assignment, priorities, or ownership.
